# ShareIt — Сервис шеринга вещей

**ShareIt** — это микросервисное REST API приложение, предоставляющее пользователям возможность делиться личными вещами.
Пользователи могут добавлять свои вещи, искать нужные предметы, бронировать их на определенные даты и оставлять отзывы.

Проект разработан в рамках обучения на курсе «Java-разработчик» от Яндекс Практикума.

---

## Технологический стек

* **Язык программирования:** Java 21
* **Фреймворки:** Spring Boot 3, Spring Web, Spring Data JPA
* **Сборка и архитектура:** Maven (многомодульный проект), REST API
* **База данных:** PostgreSQL, Hibernate
* **Качество и покрытие тестами:**
    * **JUnit 5**, **Mockito** — юнит- и интеграционное тестирование
    * **JaCoCo** — плагин контроля покрытия кода тестами (Line > 90%, Branch > 60%)
    * **Checkstyle** — статический анализ кода и соблюдение кодинг-стандартов
* **Инструменты и утилиты:** Lombok, Docker

---

## Архитектура приложения

Проект реализован по микросервисной схеме и разделен на два основных модуля:

1. **`shareit-gateway`**
    * Входная точка для клиентских запросов.
    * Отвечает за первичную валидацию данных (Jakarta Validation), аутентификацию через заголовки (`X-Sharer-User-Id`) и
      проксирование запросов к основному сервису.
2. **`shareit-server`**
    * Содержит всю бизнес-логику приложения и работу с хранилищем.
    * Взаимодействует с базой данных PostgreSQL через JPA/Hibernate.

## Основные возможности

* **Управление пользователями:** создание, обновление, получение и удаление профилей.
* **Управление вещью (Item):** добавление предметов, редактирование, поиск по названию и описанию.
* **Бронирование (Booking):**
    * Запрос на бронирование вещи на указанный интервал времени.
    * Подтверждение или отклонение запроса владельцем вещи.
    * Фильтрация бронирований по статусам (`ALL`, `CURRENT`, `PAST`, `FUTURE`, `WAITING`, `REJECTED`).
* **Отзывы (Comments):** возможность оставить отзыв и оценку на вещь после завершения аренды.
* **Запросы вещей (ItemRequest):** возможность создать запрос на вещь, которой пока нет в системе, чтобы другие
  пользователи могли предложить свои варианты.
